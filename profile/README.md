## Werkzeuge

| Werkzeug | Wofür |
| --- | --- |
| [Zeiteisen](https://github.com/ohmtools/zeiteisen) | Stundenplan-Manager: Gruppenkombinationen für den eigenen Stundenplan ausprobieren. Läuft komplett im Browser, es wird nichts gesendet. |
| [Lernhelfer](https://github.com/ohmtools/claude-plugins) | Plugin für Claude.ai: erklärt, übt mit Übungsblättern, korrigiert Lösungen und macht aus Skripten interaktive Webseiten, mit den eigenen Unterlagen. Die Vorlage für die Skripte ist [lernhelfer-skript](https://github.com/ohmtools/lernhelfer-skript). |
| [Faltungs-Animator](https://github.com/ohmtools/faltung) | Animiert die Faltung zweier Funktionen, mit freier Formeleingabe. Läuft im Browser, auch offline. |
| [Quartus-Installer](https://github.com/ohmtools/quartus-installer) | Hilft beim Installieren der Quartus-Software. |

> Die Projekte sind größtenteils mit KI entstanden: Code, Konfiguration und
> Dokumentation mit [Claude Code](https://claude.com/claude-code).
